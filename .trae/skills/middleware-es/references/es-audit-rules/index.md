## 通用检查流程

1. 确认扫描路径（`scan_path`）
2. 识别 ES 客户端类型：搜索 `ElasticsearchClient` → 新版；搜索 `RestHighLevelClient` → 旧版
3. 扫描 ES 相关代码：使用 `search_codebase` 和 `grep_code` 按规则逐项搜索
4. 逐规则检查：按 ES-001 ~ ES-008 逐项检查，记录发现的问题
5. 生成审计报告：按风险等级排序（🔴 → 🟡 → 🔵）
