# Redis 测试指引

## 五、测试指引

### 5.1 性能测试

- 推荐使用全链路性能测试
- 提前评估缓存容量、TPS、QPS、铺底数据
- 设计相关性能测试案例，确保接口符合性能要求

### 5.2 专项测试案例

| 测试案例 | 测试说明 |
|---------|---------|
| 网络抖动演练 | 模拟应用到 Redis 间数据包丢包，验证应用层是否具备重试写入机制 |
| 全量宕机演练 | 模拟 Redis 服务全部宕机，验证应用故障处置后自动重连能力 |
| 主从切换演练 | 模拟 Redis（主从模式）发生主从切换，验证应用自动重连能力 |
| 分片故障演练 | 模拟 Redis（集群模式）发生分片全部故障，验证应用自动重连能力 |
| 分片主从切换演练 | 模拟 Redis（集群模式）分片主从切换，验证应用自动重连能力 |
| 容灾切换演练 | 模拟同城双活架构下 Redis 全部宕机，验证应用自动切换至另一地 |
