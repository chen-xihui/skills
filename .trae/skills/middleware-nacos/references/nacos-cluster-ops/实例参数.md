# 二、Nacos 实例参数

## 操作 4: 查询实例参数

| 属性 | 说明 |
|------|------|
| 操作类型 | 查询实例参数 |
| resource | `nacosclusterconfig` |
| action | `get` |
| 风险等级 | 🟢 低风险 |
| 需确认 | 否 |

```bash
paas-cli get nacosclusterconfig --gateway-config=config/gateway.yaml -f config/nacos/iteration-nacos-cluster-config-get.yaml
```

## 操作 5: 更改实例参数

| 属性 | 说明 |
|------|------|
| 操作类型 | 更改实例参数 |
| resource | `nacosclusterconfig` |
| action | `update` |
| 风险等级 | 🟡 中风险 |
| 需确认 | 是 |

```bash
paas-cli update nacosclusterconfig --gateway-config=config/gateway.yaml -f config/nacos/iteration-nacos-cluster-config-update.yaml
```

**确认流程**：向用户展示命令及影响（参数变更可能触发节点重启，影响集群可用性），等待确认后执行。
