# CLI 安全规则（共享参考文件）

本文件定义了所有中间件 Skill 调用外部 CLI 工具（paas-cli、bianque）时必须遵守的安全规则。三个专项 Skill（Nacos、Redis、ES）统一引用本文件。

---

## 1. 命令注入防护

### 1.1 参数化构造

智能体构造终端命令时，必须通过变量替换而非字符串拼接传入参数，避免 shell 元字符注入。

**正确做法**：
```bash
# 参数通过变量替换
paas-cli es info --project j036x0 --env DEV
```

**错误做法**：
```bash
# 字符串拼接（禁止）
cmd = "paas-cli es info --project " + user_input + " --env " + env_input
```

### 1.2 输入校验白名单

| 参数 | 合法值规则 | 合法示例 | 非法示例 |
|------|-----------|---------|---------|
| project_id | 仅允许小写字母、数字，格式如 j036x0 | `j036x0` ✅ | `; rm -rf` ❌ |
| env | 枚举值：DEV / SIT / SRV | `DEV` ✅ | `DEV; ls` ❌ |
| service_name | 仅允许字母、数字、下划线、短横线 | `order-service` ✅ | `$(whoami)` ❌ |
| version | 语义化版本号格式 | `7.10.2` ✅ | `7.10.2 && cat /etc/passwd` ❌ |
| count / replicas / nodes / shards | 正整数 | `3` ✅ | `3 || echo hack` ❌ |
| index_name | ES 索引命名规范（小写字母、数字、短横线） | `log-2026` ✅ | `log"; rm -rf /` ❌ |
| mode | 枚举值：standalone / sentinel / cluster | `cluster` ✅ | `cluster; ls` ❌ |
| alias | 字母、数字、短横线、下划线 | `log-alias` ✅ | `$(whoami)` ❌ |
| policy | 枚举值：noeviction / allkeys-lru / volatile-lru 等 | `allkeys-lru` ✅ | `allkeys-lru && echo hack` ❌ |
| namespace | 仅允许小写字母、数字、短横线 | `myns` ✅ | `myns; ls` ❌ |
| instance | 仅允许字母、数字、短横线 | `myes` ✅ | `myes && cat` ❌ |
| type | 枚举值：cluster / sentinel | `cluster` ✅ | `cluster; rm` ❌ |

### 1.3 危险字符过滤

所有参数值中不得包含以下 shell 元字符：

| 字符 | 说明 |
|------|------|
| `;` | 命令分隔符 |
| `|` | 管道符 |
| `&` | 后台运行/逻辑与 |
| `$` | 变量引用 |
| `` ` `` | 命令替换 |
| `(` `)` | 子 shell |
| `{` `}` | 花括号展开 |

**处理方式**：如检测到参数中包含上述字符，拒绝执行命令并向用户提示：
```
❌ 参数包含非法字符，命令已拒绝执行。
参数名：{param_name}
参数值：{param_value}
非法字符：{detected_chars}

请检查输入是否正确。如确需使用特殊字符，请联系管理员。
```

## 2. 高风险操作确认

### 2.1 操作风险分级

| 风险等级 | 操作类型 | 确认要求 |
|---------|---------|---------|
| 🟢 低风险 | 查询、状态检查、信息查看 | 无需确认，直接执行 |
| 🟡 中风险 | 创建、扩缩容、配置变更、索引操作 | 向用户展示即将执行的命令，等待用户确认后执行 |
| 🔴 高风险 | 删除、升级、主备切换 | 向用户展示命令及影响范围，必须获得明确确认（用户回复"确认"）后方可执行 |

### 2.2 确认流程

#### 🟡 中风险操作确认

```
即将执行以下操作：
  命令：{完整命令}
  说明：{操作说明}
  影响：{简要影响}

是否继续执行？
```

- 用户回复"是"/"确认"/"继续"等肯定回复 → 执行命令
- 用户回复"否"/"取消"等否定回复 → 取消操作
- 用户超时未回复 → 取消操作

#### 🔴 高风险操作确认

```
⚠️ 高风险操作 ⚠️

即将执行以下操作：
  命令：{完整命令}
  说明：{操作说明}
  影响范围：
    - {影响1}
    - {影响2}
    - 此操作不可逆

请输入"确认"以执行此操作：
```

- 用户必须明确输入"确认"后才执行
- 其他任何回复（包括"是"、"ok"等）均不执行
- 用户拒绝或超时未确认 → 取消操作，不执行任何命令

## 3. 敏感信息处理

### 3.1 密码处理

- Skill 中不得以明文形式将密码写入代码文件
- 生成的配置文件中使用占位符（如 `${ES_PASSWORD}`、`${NACOS_PASSWORD}`、`${REDIS_PASSWORD}`）
- 引导用户通过以下方式注入实际密码：
  - 环境变量
  - Spring Cloud Config
  - Vault 等密钥管理系统
  - Kubernetes Secrets

### 3.2 连接地址

- 优先从 paas-cli 动态获取连接地址
- 避免在 Skill 指令中硬编码任何环境地址
- 配置文件中使用占位符（如 `${ES_HOST}`）

## 4. 操作审计

### 4.1 审计要求

- 每次执行的 paas-cli / bianque 命令及结果，应在智能体对话中完整展示
- 形成天然的操作审计记录

### 4.2 审计信息

输出中应包含：
- 执行时间
- 完整命令（脱敏后，密码替换为 ***）
- 执行结果摘要
- 执行耗时

---

## 5. 错误处理

### 5.1 命令执行失败

向用户展示 stderr 内容，并提供排查建议：

```
❌ 命令执行失败

命令：{执行的命令}
错误信息：{stderr 内容}

排查建议：
  1. 检查 paas-cli 是否已安装：paas-cli --version
  2. 检查网络连通性：paas-cli ping
  3. 检查项目组权限：paas-cli auth check --project {project_id}
  4. 如命令超时，可添加 --timeout 参数重试
```

### 5.2 超时处理

- paas-cli 命令默认超时 30 秒
- bianque 诊断命令默认超时 60 秒
- 可通过 `--timeout` 参数调整超时时间

### 5.3 权限不足

提示用户联系管理员授权：
```
❌ 权限不足

当前用户无权执行此操作，请联系项目管理员授权。
项目组：{project_id}
环境：{env}
操作：{action}
```
