# SDR-002：禁止 RedisTemplate.keys()

| 属性 | 说明 |
|------|------|
| 规则ID | SDR-002 |
| 风险等级 | 风险 |
| 规则描述 | 禁止使用 opsForKeys().keys() |

## 问题说明

Redis 的 `KEYS` 命令会遍历整个键空间（即数据库中所有键），时间复杂度为 O(N)。当 Redis 中存储了大量键时，`KEYS` 命令将长时间阻塞 Redis 服务端的主线程（Redis 单线程模型），导致所有其他客户端的请求排队等待，造成服务整体不可用。

在生产环境中，即使键数量只有几十万，一次 `KEYS *` 也可能阻塞 Redis 数百毫秒到数秒，期间所有读写请求均超时。这也是 Redis 官方文档明确警告禁止在生产环境使用 `KEYS` 命令的原因。

替代方案是使用 `SCAN` 命令，它基于游标迭代，每次只返回少量结果，不会长时间阻塞 Redis 主线程。

## 检查方法

- 静态分析：搜索所有 `.keys(` 调用，确认是否来自 `RedisTemplate` 或 `StringRedisTemplate`
- 检查是否存在 `redisTemplate.keys(` 或 `redisTemplate.opsForKeys().keys(` 模式
- 建议替换为 `redisTemplate.scan()` 方案
- 脚本化检查：`python scripts/check_sdr_002.py <项目根目录>`

## 违规示例

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.stereotype.Service;
import java.util.Set;

@Service
public class UserSessionService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 违规：使用 keys() 遍历所有匹配的键
    // 当 Redis 中键数量很大时，会长时间阻塞 Redis 主线程
    public Set<String> getAllUserSessions(String userId) {
        return redisTemplate.keys("session:user:" + userId + ":*");
    }

    // 违规：使用 keys("*") 获取所有键，危险程度更高
    public void cleanAllSessions() {
        Set<String> allSessionKeys = redisTemplate.keys("session:*");
        for (String key : allSessionKeys) {
            redisTemplate.delete(key);
        }
    }
}
```

## 合规示例

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.Cursor;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.ScanOptions;
import org.springframework.stereotype.Service;
import java.util.ArrayList;
import java.util.List;

@Service
public class UserSessionService {

    private static final int SCAN_BATCH_SIZE = 1000;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 合规：使用 scan 替代 keys，基于游标迭代不阻塞 Redis
    public List<String> getAllUserSessions(String userId) {
        List<String> sessionKeys = new ArrayList<>();
        ScanOptions scanOptions = ScanOptions.scanOptions()
                .match("session:user:" + userId + ":*")
                .count(SCAN_BATCH_SIZE)
                .build();
        try (Cursor<String> cursor = redisTemplate.scan(scanOptions)) {
            while (cursor.hasNext()) {
                sessionKeys.add(cursor.next());
            }
        }
        return sessionKeys;
    }

    // 合规：使用 scan 分批获取后删除，避免一次性加载所有键
    public void cleanAllSessions() {
        ScanOptions scanOptions = ScanOptions.scanOptions()
                .match("session:*")
                .count(SCAN_BATCH_SIZE)
                .build();
        try (Cursor<String> cursor = redisTemplate.scan(scanOptions)) {
            List<String> batch = new ArrayList<>();
            while (cursor.hasNext()) {
                batch.add(cursor.next());
                if (batch.size() >= SCAN_BATCH_SIZE) {
                    redisTemplate.delete(batch);
                    batch.clear();
                }
            }
            if (!batch.isEmpty()) {
                redisTemplate.delete(batch);
            }
        }
    }
}
```
