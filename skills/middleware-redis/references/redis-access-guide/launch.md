# Redis 上线指引

## 六、上线指引

### 6.1 前置资源准备

- 通过 IT 综合管理系统发起软件维护需求
- 流程附件中提供系统概要设计说明书，明确：
  - 接入区域
  - 服务部署模式
  - 资源需求
  - 持久化模式
  - 容灾要求
  - 定制化需求（淘汰策略、配置参数等）

### 6.2 告警规则确认

- 缓存服务默认接入技术中台可观测底座
- 评估默认模板的监控项、告警阈值是否满足需求
- 根据业务特点调整监控项和告警项
- 研发测试环境验证通过后提交至生产运维人员更新

### 6.3 接入前置检查

- 客户端配置确认
- 生产服务检查
- 服务部署模式确认
- 生产资源确认
- 网络连通性确认
- 连接认证确认

### 6.4 应急卡片准备

- 结合缓存服务使用情况完成应急预案（卡片）编写
- 提交至生产应用运维人员
