## 检查流程

1. 确认扫描路径
2. 识别 ES 客户端类型（新版 ElasticsearchClient / 旧版 RestHighLevelClient）
3. 按 ES-001 ~ ES-008 逐项检查
4. 生成审计报告，按风险等级排序（🔴 → 🟡 → 🔵）
