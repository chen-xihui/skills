# 测试指引

## 5.1 性能测试

- 推荐使用全链路性能测试
- 提前评估 ES 容量、TPS、QPS、铺底数据
- 设计相关性能测试案例，确保接口符合性能要求

## 5.2 专项测试案例

| 专项测试案例 | 测试说明 |
|-------------|---------|
| ES 单个 data 节点宕机 | 模拟 ES data 单个节点宕机，验证故障处置恢复后应用是否可自动重连及业务代码正确重新查询、创建 |
| ES 单个 master 节点宕机 | 模拟 ES master 单个节点宕机，验证故障处置恢复后应用是否可自动重连及业务代码正确重新查询、创建 |
| ES 全量 data 节点宕机 | 模拟 ES data 全量节点宕机，验证故障处置恢复后应用是否可自动重连及业务代码正确重新查询、创建 |
| ES 全量 master 节点宕机 | 模拟 ES master 全量节点宕机，验证故障处置恢复后应用是否可自动重连及业务代码正确重新查询、创建 |
| ES 节点网络延迟演练 | 模拟应用端 ES 网络延迟导致通信异常出现数据丢失场景，验证应用是否具备写入失败重试和补偿能力 |
| ES 节点网络丢包演练 | 模拟应用端到 ES 网络丢包导致通信异常出现数据丢失场景，验证应用是否具备写入失败重试和补偿能力 |

可根据接入系统可用性要求补充混沌案例进行专项测试。
