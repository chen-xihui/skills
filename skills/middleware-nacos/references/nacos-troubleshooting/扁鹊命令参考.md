# 4. 扁鹊诊断命令参考

> 详细命令格式和参数说明参见 `命令速查手册.md`

## 4.1 完整诊断命令

```bash
bianque nacos check -n {namespace} -i {instance} -v true
```

### 全局参数

所有 `bianque` 命令都支持全局参数 `--token-file` 指定权限验证脚本文件路径。

## 4.2 诊断命令变体

```bash
# 综合检查并展示详情
bianque nacos check -n {namespace} -i {instance} -v true

# 指定日志检查行数（默认 1000）
bianque nacos check -n {namespace} -i {instance} -v true -l 2000

# 基本检查（不展示详情）
bianque nacos check -n {namespace} -i {instance}

# 客户端连通性验证
bianque nacos client -n {namespace} -i {instance}
```

## 4.3 返回格式

```json
{
  "status": "success|error",
  "findings": [
    {
      "type": "health|raft|log",
      "severity": "critical|warning|info",
      "message": "描述信息",
      "details": {}
    }
  ],
  "logs": ["相关日志条目"],
  "suggestions": ["处理建议"]
}
```
