# 四、Nacos 备份与恢复

## 操作 11: 备份集群

| 属性 | 说明 |
|------|------|
| 操作类型 | 备份集群 |
| resource | `nacosclusterbackup` |
| action | `create` |
| 风险等级 | 🟢 低风险 |
| 需确认 | 否 |

```bash
paas-cli create nacosclusterbackup --gateway-config=config/gateway.yaml -f config/nacos/iteration-nacos-cluster-backup-create.yaml
```

## 操作 13: 恢复集群

| 属性 | 说明 |
|------|------|
| 操作类型 | 恢复集群 |
| resource | `nacosclusterrestore` |
| action | `update` |
| 风险等级 | 🔴 高风险 |
| 需确认 | 是 |

```bash
paas-cli update nacosclusterrestore --gateway-config=config/gateway.yaml -f config/nacos/iteration-nacos-cluster-restore.yaml
```

**确认流程**：恢复操作将覆盖当前集群数据，必须向用户明确说明影响并等待确认。
