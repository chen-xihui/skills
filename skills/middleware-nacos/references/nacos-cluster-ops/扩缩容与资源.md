# 三、Nacos 扩缩容与资源

## 操作 7: 集群扩缩容

| 属性 | 说明 |
|------|------|
| 操作类型 | 集群扩缩容 |
| resource | `nacosclusterreplicas` |
| action | `update` |
| 风险等级 | 🟡 中风险 |
| 需确认 | 是 |

```bash
paas-cli update nacosclusterreplicas --gateway-config=config/gateway.yaml -f config/nacos/iteration-nacos-cluster-replicas-update.yaml
```

**注意事项**：
- Nacos 集群建议奇数节点（1/3/5），确保 Raft 选举过半
- 缩容时需确保剩余节点数满足 Raft 多数派
