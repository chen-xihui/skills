# SDR-003：必须配置 commandTimeout

| 属性 | 说明 |
|------|------|
| 规则ID | SDR-003 |
| 风险等级 | 风险 |
| 规则描述 | RedisTemplateFactory 必须配置超时 |

## 问题说明

Spring Data Redis 的 `LettuceConnectionFactory` 或 `JedisConnectionFactory` 在未显式配置 `commandTimeout` 时，默认超时时间为 60 秒。如果 Redis 服务端因负载过高、网络抖动或主从切换而响应缓慢，调用线程将被阻塞最多 60 秒等待响应。在高并发场景下，大量线程同时阻塞在 Redis 调用上，会迅速耗尽线程池（如 Tomcat 工作线程），导致应用整体不可用——即所谓的"线程堆积"雪崩。

必须根据业务 SLA 合理设置 `commandTimeout`（建议 500ms~3s），确保 Redis 调用快速失败，配合重试或降级策略保障系统韧性。

## 检查方法

- 静态分析：搜索所有 `LettuceConnectionFactory` 和 `JedisConnectionFactory` Bean 定义，检查是否配置了超时
- 检查是否调用了 `setCommandTimeout()` 或在构造函数中传入了 `Duration`
- 检查 `application.yml` 中 `spring.redis.timeout` 配置是否存在
- 脚本化检查：`python scripts/check_sdr_003.py <项目根目录>`

## 违规示例

```java
import io.lettuce.core.RedisClient;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.connection.RedisStandaloneConfiguration;
import org.springframework.data.redis.connection.lettuce.LettuceConnectionFactory;

@Configuration
public class RedisConfig {

    @Bean
    // 违规：未设置 commandTimeout，默认 60 秒
    // Redis 响应慢时线程将阻塞 60 秒，高并发下线程堆积导致服务不可用
    public RedisConnectionFactory redisConnectionFactory() {
        RedisStandaloneConfiguration config = new RedisStandaloneConfiguration();
        config.setHostName("127.0.0.1");
        config.setPort(6379);
        return new LettuceConnectionFactory(config);
    }
}
```

```yaml
# application.yml
# 违规：未配置 spring.redis.timeout
spring:
  redis:
    host: 127.0.0.1
    port: 6379
    # timeout 未设置
```

## 合规示例

```java
import io.lettuce.core.RedisClient;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.connection.RedisStandaloneConfiguration;
import org.springframework.data.redis.connection.lettuce.LettuceConnectionFactory;
import org.springframework.data.redis.connection.lettuce.LettuceClientConfiguration;
import java.time.Duration;

@Configuration
public class RedisConfig {

    private static final long COMMAND_TIMEOUT_MS = 500;

    @Bean
    public RedisConnectionFactory redisConnectionFactory() {
        RedisStandaloneConfiguration serverConfig = new RedisStandaloneConfiguration();
        serverConfig.setHostName("127.0.0.1");
        serverConfig.setPort(6379);

        // 合规：显式设置 commandTimeout 为 500ms
        LettuceClientConfiguration clientConfig = LettuceClientConfiguration.builder()
                .commandTimeout(Duration.ofMillis(COMMAND_TIMEOUT_MS))
                .shutdownTimeout(Duration.ofMillis(100))
                .build();

        return new LettuceConnectionFactory(serverConfig, clientConfig);
    }
}
```

```yaml
# application.yml
# 合规：通过配置文件设置超时
spring:
  redis:
    host: 127.0.0.1
    port: 6379
    timeout: 500ms  # 合规：显式设置 commandTimeout
```

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.connection.RedisStandaloneConfiguration;
import org.springframework.data.redis.connection.jedis.JedisConnectionFactory;

@Configuration
public class RedisJedisConfig {

    @Bean
    public RedisConnectionFactory redisConnectionFactory() {
        RedisStandaloneConfiguration config = new RedisStandaloneConfiguration();
        config.setHostName("127.0.0.1");
        config.setPort(6379);

        JedisConnectionFactory factory = new JedisConnectionFactory(config);
        // 合规：对 Jedis 连接工厂同样需要设置超时
        factory.setCommandTimeout(Duration.ofMillis(500));
        return factory;
    }
}
```
