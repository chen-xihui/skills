# SDR-001：禁止使用默认序列化器

| 属性 | 说明 |
|------|------|
| 规则ID | SDR-001 |
| 风险等级 | 严重 |
| 规则描述 | 必须配置 RedisTemplate 序列化方式 |

## 问题说明

Spring Data Redis 的 `RedisTemplate` 默认使用 `JdkSerializationRedisSerializer`，该序列化器存在以下严重问题：

1. **安全风险**：Java 原生序列化存在反序列化漏洞（如 CVE-2015-4852 等），攻击者可构造恶意序列化数据执行任意代码。
2. **跨语言不可用**：JDK 序列化产出的二进制数据仅 Java 应用可读，其他语言（Python、Go、Node.js）无法解析。
3. **内存开销大**：JDK 序列化会附带类元信息、引用关系等额外数据，序列化后的体积远大于 JSON，浪费 Redis 内存。
4. **可读性差**：在 Redis CLI 中查看数据时只能看到乱码，无法直接排查问题。

必须显式配置 `StringRedisSerializer` 作为 key 的序列化器，配置 `GenericJackson2JsonRedisSerializer` 或 `Jackson2JsonRedisSerializer` 作为 value 的序列化器。

## 检查方法

- 静态分析：搜索所有 `RedisTemplate` Bean 定义，检查是否配置了序列化器
- 检查 `setKeySerializer` 和 `setValueSerializer` 是否被调用
- 检查是否使用了 `StringRedisTemplate`（内置 String 序列化器）作为替代
- 脚本化检查：`python scripts/check_sdr_001.py <项目根目录>`

## 违规示例

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;

@Configuration
public class RedisConfig {

    @Bean
    // 违规：未配置任何序列化器，使用默认的 JdkSerializationRedisSerializer
    // 存储的数据在 Redis 中为二进制乱码，无法跨语言读取，且存在安全风险
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        // 未调用 setKeySerializer / setValueSerializer
        return template;
    }
}
```

## 合规示例

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);

        // 合规：Key 使用 String 序列化器，可读性强
        StringRedisSerializer stringSerializer = new StringRedisSerializer();
        template.setKeySerializer(stringSerializer);
        template.setHashKeySerializer(stringSerializer);

        // 合规：Value 使用 JSON 序列化器，跨语言兼容、内存占用小
        GenericJackson2JsonRedisSerializer jsonSerializer = new GenericJackson2JsonRedisSerializer();
        template.setValueSerializer(jsonSerializer);
        template.setHashValueSerializer(jsonSerializer);

        template.afterPropertiesSet();
        return template;
    }
}
```

```java
// 合规替代方案：对于纯字符串场景，直接使用 Spring 内置的 StringRedisTemplate
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;

@Service
public class CacheService {

    @Autowired
    private StringRedisTemplate stringRedisTemplate; // 内置 String 序列化器，无需额外配置

    public void setCache(String key, String value) {
        stringRedisTemplate.opsForValue().set(key, value);
    }

    public String getCache(String key) {
        return stringRedisTemplate.opsForValue().get(key);
    }
}
```
